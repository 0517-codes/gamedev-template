# 設計
## 登場するもの
- プレイヤー、車、爆弾
- 足を速くするスキル、ワープスキル（３秒に１回使用可）
- ラウンド切り替え演出
- 合計秒数
- 難易度（上がるほど車が増え速度が上がる）
- 勝利演出
- 上矢印キーで前進、下矢印キーで後進、Fキーで連射、Rキーでリロード、スペースキーでリロード、Ｇキーで7秒間迷路の答えを表示

| オブジェクト | 持ってる情報 |
| ----------- | ----------- |
| プレイヤー　 | 秒数、スコア、プレイヤー1、プレイヤー2 |
| 車 | 速度、出現頻度 |
| 爆弾 | 速度、出現頻度 |
| HUD | 秒数、スコア、ラウンド数|

## 条件
タイトル画面  
　↓（Enterキー）
ラウンド開始（Round1）  
　↓
プレイ中  
　↓（Escキー）
ポーズ中  
　↓（Escキー）
ポーズ解除  
　↓
車に2回当たる  
　↓
ゲームオーバー演出（爆発エフェクト）  
　↓
次のラウンドへ進む（Round2）  
　↓
ラウンド3へ進む（Round3）  
　↓
ラウンド終了 → 合計秒数判定 → 勝利 or 敗北演出
